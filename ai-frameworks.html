Popular AI Frameworks

🦜 LangChain

What it is: A framework for building applications powered by LLMs by chaining together prompts, models, tools, and data sources

Key Components

• Prompt Templates
• Models (LLMs & Chat Models)
• Chains (LCEL)
• Retrievers & Vector Stores
• Memory & Tools

Use Cases

• RAG (chat with your documents)
• Chatbots with memory
• Summarization pipelines
• Tool-using agents
from langchain_core.prompts import ChatPromptTemplate from langchain_openai import ChatOpenAI prompt = ChatPromptTemplate.from_template("Explain {topic} in simple terms") chain = prompt | ChatOpenAI(model="gpt-4o-mini") print(chain.invoke({"topic": "embeddings"}).content)

How it works: Each piece (prompt, model, output parser, retriever) is a building block you connect with the | operator, so data flows from one step to the next like a pipeline.

🕸️ LangGraph

What it is: A library from the LangChain team for building stateful, multi-step AI agents as graphs of nodes and edges
State
Shared data passed between nodes
→
Nodes
Functions / LLM calls / tools
→
Edges
Decide which node runs next

Why LangGraph?

• Loops & conditional branching
• Persistent memory (checkpoints)
• Human-in-the-loop approval
• Multi-agent collaboration

Use Cases

• ReAct agents
• Research assistants
• Customer-support workflows
• Planner → executor agents
from langgraph.graph import StateGraph, START, END from typing import TypedDict class State(TypedDict): question: str answer: str def answer_node(state: State): return {"answer": f"Thinking about: {state['question']}"} graph = StateGraph(State) graph.add_node("answer", answer_node) graph.add_edge(START, "answer") graph.add_edge("answer", END) app = graph.compile() print(app.invoke({"question": "What is RAG?"}))

How it works: Where LangChain chains run in a straight line, LangGraph lets the agent loop, branch, and revisit steps until the task is done.

🤗 Hugging Face

What it is: The open-source hub for AI — hundreds of thousands of pretrained models, datasets, and demo apps, plus the transformers library to use them

Ecosystem

• Model Hub & Datasets
• Transformers library
• Tokenizers
• PEFT / LoRA fine-tuning
• Spaces (Gradio / Streamlit demos)

Common Tasks

• Sentiment analysis
• Text generation & summarization
• Translation
• Image classification
from transformers import pipeline classifier = pipeline("sentiment-analysis") print(classifier("I love learning about AI!")) # [{'label': 'POSITIVE', 'score': 0.9998}]

How it works: The pipeline() function downloads a pretrained model and its tokenizer, so you can run state-of-the-art models in just a few lines of code.

🤖 OpenAI

What it is: The company behind ChatGPT and the GPT models, offering an API and SDK to add powerful language, vision, and audio models to your apps

Models & APIs

• GPT models (chat & reasoning)
• Embeddings
• DALL·E (image generation)
• Whisper (speech-to-text)
• Function / tool calling

Use Cases

• Chatbots & assistants
• Semantic search with embeddings
• Structured data extraction
• Code generation
from openai import OpenAI client = OpenAI() # reads OPENAI_API_KEY from env response = client.chat.completions.create( model="gpt-4o-mini", messages=[{"role": "user", "content": "Explain transformers in one line"}], ) print(response.choices[0].message.content)

How it works: You send a list of messages (system, user, assistant) to the API and the model returns the next reply. Models run on OpenAI's servers, so no GPU is needed locally.

🦙 LLaMA 2

What it is: Meta's family of open-weight large language models (7B, 13B, and 70B parameters) that you can download, run locally, and fine-tune
7B
Fast, runs on a laptop GPU
→
13B
Balanced quality & speed
→
70B
Highest quality, needs big GPUs

Highlights

• Trained on 2 trillion tokens
• 4K token context window
• Llama-2-Chat tuned with RLHF
• Free for research & commercial use

Ways to Run It

• Hugging Face Transformers
• Ollama / llama.cpp (local)
• Fine-tune with LoRA / QLoRA
• Cloud (AWS, Azure, GCP)
from transformers import pipeline generator = pipeline("text-generation", model="meta-llama/Llama-2-7b-chat-hf") print(generator("What is machine learning?", max_new_tokens=100)[0]["generated_text"])

How it works: Because the weights are open, you can run LLaMA 2 on your own hardware, keep data private, and fine-tune it for your specific domain.

Choosing the Right Framework

Key Takeaways:

  • OpenAI — quickest way to get top-quality results through an API
  • LLaMA 2 — open weights for local, private, and fine-tuned models
  • Hugging Face — the go-to hub for open models, datasets, and fine-tuning tools
  • LangChain — glue code for prompts, retrieval (RAG), and tool use
  • LangGraph — for complex agents that need loops, memory, and branching
