# 🤖 Sai's AI Learning Blog

A modern, interactive blog documenting my journey learning Artificial Intelligence with stunning visual effects and animations.

## ✨ Features

- **Interactive UI**: Glow animations on topic cards
- **AI Chatbot**: Built-in offline assistant for AI questions (no API key, no internet, free)
- **WebGL Background**: Dynamic particle animations
- **Responsive Design**: Works on all devices
- **Multiple Topics**: Comprehensive AI learning sections

## 📚 Topics Covered

- **AI Basics**: Supervised learning, classification, regression, clustering
- **Prompt Engineering**: Crafting effective AI prompts
- **Deep Learning**: Neural networks, CNNs, RNNs, Transformers
- **Generative AI**: ChatGPT, Gemini, Midjourney
- **AI on Cloud**: Vertex AI, AWS SageMaker, Azure AI
- **Data Engineering**: Preprocessing, pipelines, ML workflows
- **AI Frameworks**: LangChain, LangGraph, Hugging Face, OpenAI, LLaMA 2, LangChain vs LangGraph
- **LangChain in Detail**: models, prompts, parsers, LCEL, memory, RAG, tools & agents, LangSmith
- **LangGraph in Detail**: state, edges & loops, ReAct agents, persistence, human-in-the-loop, multi-agent

## 🚀 Getting Started

1. Clone the repository:
```bash
git clone https://github.com/SaiKiran20011060/Sai-s_blog.git
```

2. Open `index.html` in your browser, or run a local server:
```bash
python -m http.server 8000
```
Then visit http://localhost:8000

The chatbot works fully offline, so no backend or API key is needed.

## 🛠️ Technologies Used

- **Frontend**: HTML5, CSS3, JavaScript
- **Graphics**: WebGL for particle animations
- **Styling**: Custom CSS with glassmorphism effects
